# Google Flow Image Generation Guide
## Web Development Agency — Complete Visual Asset Specification

This comprehensive guide contains the complete image specifications, inventory tables, and copy-ready **Google Flow** generative AI prompts for all visual placeholders across the entire 26-page **WEB DEVELOPMENT AGENCY** demonstration website.

---

### Global Design & Generation Guidelines
All prompts are calibrated to harmonize with the agency's dark aesthetic:
- **Primary Color Palette:** Dark charcoal base (`#080D18`), rich navy slate (`#101827`), card containers (`#141F32`), vibrant electric blue (`#5B8CFF`), cyan teal (`#36D6E8`), and violet purple (`#9878FF`).
- **Visual Style:** Ultra-high-resolution 3D glassmorphic renders, modern cinematic studio photography, and sleek minimalist UI interfaces. Clean, futuristic, high-tech, and premium digital agency look.
- **Negative Prompt & Exclusions:** Absolutely no text, no alphabets, no brand names, no fictional agency logos, no watermarks, no distorted fingers or hands, and no messy clutter.
- **Negative Space:** Prompts specify explicit negative space areas (left, right, or top) to accommodate typography and UI badges without visual interference.

   - Ensure negative prompt includes: *"text, words, watermarks, brand names, distorted anatomy, clutter"*.

2. **Save & Optimize:**
   - Download the generated image.
   - Convert or export the image as `.webp` format at 85-90% quality to ensure rapid loading speeds under 150KB.
   - Rename the file to match the **exact filename** listed in Section A (e.g., `hero-agency-workspace.webp`).

3. **Place in Asset Directory:**
   - Move all saved `.webp` files into:
     ```text
     assets/images/
     ```

4. **Update HTML Placeholders:**
   - Find the placeholder in the target `.html` file:
     ```html
     <!-- Before: Placeholder -->
     <div class="img-placeholder" data-img="hero-agency-workspace.webp" style="aspect-ratio: 16/9;">
       ...
     </div>
     ```

     ```html
     <!-- After: Active Image -->
     <img src="assets/images/hero-agency-workspace.webp" alt="Modern Web Development Agency Studio Workstation" class="img-fluid" loading="lazy">
     ```
   - The `.img-fluid` class will automatically respect the container width, rounded borders, and responsive scaling.
